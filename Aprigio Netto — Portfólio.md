# Aprigio Netto — Portfólio

Site pessoal de **Aprigio Netto**, desenvolvido com HTML, CSS e JavaScript puro.

## Visão geral

O projeto apresenta sua atuação como desenvolvedor Full Stack, sua stack tecnológica, objetivos e formas de contato em uma experiência visual responsiva e sem dependências de framework.

## Estrutura

- `index.html` — estrutura e conteúdo da página
- `styles.css` — identidade visual, responsividade e animações
- `script.js` — menu mobile e efeitos de entrada
- `manus-routes.json` — rota principal do site
- `assets/foto-perfil.png` — foto de perfil do portfólio

## Como executar

Basta abrir o arquivo `index.html` no navegador. Para publicar no GitHub, acesse **Settings → Pages**, selecione a branch `main` e a pasta `/ (root)` como fonte.

## Personalização rápida

1. Substitua o link do GitHub e os textos da seção de contato, se necessário.
2. Adicione links reais aos projetos na seção “Projetos em destaque”.
3. Atualize os links sociais do rodapé quando desejar.
